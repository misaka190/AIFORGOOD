## Route design

- /: 首页
- /upload: 上传页面
- /analysis: 分析中页面
- /results: 结果页面
- /gradcam: Grad-CAM 页面
- /review: 医生复核页面
- /history: 历史记录页面
- /privacy: 隐私与伦理页面

## Component design

- layout/top-nav: 顶部导航
- layout/app-shell: 全局框架
- ui/button: 基础按钮
- ui/page-header: 页面标题区
- ui/risk-level-pill: 风险等级标识
- ui/disclaimer-panel: 免责声明与安全提示
- ui/state-panel: 错误状态和空状态
- upload/upload-form: 上传与知情同意表单
- results/probability-chart: 标签概率条形图
- review/review-form: 医生复核表单

## API service encapsulation

lib/api.ts 提供 Axios 实例和前端服务封装：

- uploadCxr(formData)
- fetchAnalysisResult(predictionId)
- fetchHistory()

当前为便于界面演示，接口异常时回退到 mock 数据。

## TypeScript types

types/index.ts 包含：

- RiskLevel
- LabelProbability
- RiskAssessment
- AnalysisResult
- ReviewAction
- HistoryItem

## Medical UI copy guidelines

- 使用“风险提示”“辅助分析”“建议复核”
- 不使用“确诊”“患有”“治疗方案”
- 对不确定结果明确提示医生复核
- 对热力图明确提示仅用于辅助理解

## Error and empty states

- 历史记录为空时使用 StatePanel 提示去上传页面
- API 异常可扩展为 error tone 的 StatePanel
- 上传页对文件格式、大小和勾选状态做即时校验

## Tailwind medical theme

主题使用临床绿色与暖橙强调色，避免常见通用科技风。核心变量定义在 app/globals.css，Tailwind 扩展在 tailwind.config.ts。

## Deploy to Vercel

1. Import the frontend directory as a Next.js project.
2. Set NEXT_PUBLIC_API_BASE_URL.
3. Run build command: npm run build.
4. Use output generated by Next.js.

## Deploy with Docker

```bash
docker build -t medvision-cxr-frontend ./frontend
docker run -p 3000:3000 --env-file ./frontend/.env.example medvision-cxr-frontend
```
